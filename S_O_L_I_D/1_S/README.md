# S - Single Responsibility Principle

# Principles

The Single Responsibility Principle states two key principles:

A class or method should have only one reason to change.

A class or method should have only one responsibility to take care of.

# Explanation

This principle ensures that a class or method focuses on a single responsibility, making the system more maintainable and easier to understand.

By following SRP, we can reduce the impact of changes and improve code scalability.
